**FRAPANOL (FRENCH AND SPANISH TUTOR)**

It is a lightweight single-file language learning application that lets you learn French and Spanish through games and exercises. The whole idea is to create a distraction-free environment where you can learn vocabulary, grammar, and pronunciation at your own pace.

The games are all turned into an XP, streak, achievements, and levels system to keep you motivated while learning the language. Your progress and all the games settings are stored in your browser, which means all your data is private and secure since it's not stored anywhere else on the internet.

*Core Learning Activities:*

Vocabulary & Phrases: More than 120 words/phrases in each language with native voice text to speech
Interactive Games: Test your language skills with Flashcards, multiple choice questions, and a speed paced Matching game
Listening & Spelling: Work on your ear training and spelling abilities with dictation and a spelling challenge that gives points for correct answers
Verb Conjugator: View the different forms of the verbs with a table of the most common verbs in the Present, Past, and Near Future tenses.
AI Tutor: Chat with an embedded chat bot using an API key to help you learn more about grammar specific questions.

*Secret background changer:*

To use the custom background feature, place images in the same folder as your index.html with the following names:
French: f.png, f1.png, f2.png ... up to f6.png
Spanish: s.png, s1.png, s2.png ... up to s6.png
Click the flag in the header to cycle through them!

*How to run it?:*

Prerequisites
You do not need a database or a complex backend. You only need a modern web browser.
Running via Localhost (Recommended)
To ensure the Speech Synthesis API and AI Tutor work correctly, it is best to run the app on a local server rather than opening the file directly.
Using VS Code: Install the Live Server extension, open the HTML file, and click "Go Live".
Using Python: Run python -m http.server 8000 in your terminal inside the project folder.
Using Node.js: Run npx http-server.
Access the app at http://localhost:8000 (or the port provided).
